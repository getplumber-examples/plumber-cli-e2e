# plumber-cli-e2e

E2E fixtures for https://github.com/getplumber/plumber. Not a real project.
One branch per test case. The content of each branch is generated from
`v1/testdata/e2e/github/<case>/` in the plumber repository by `v1/testdata/e2e/sync.sh`:
edit it there, never here.

- `clean`
- `findings`
- `invalid-yaml`
- `no-workflows`
- `reusable-local`
